Сила (PvE)

Статьи / Гайды

Открыть в интерактивной вики →

Сила (PvE) — это показатель, определяющий силу нашего персонажа на основе его характеристик и психомодификаторов со снаряжения. Ни для чего в игре он не требуется, это чисто информационная характеристика. Его можно использовать, чтобы сравнить силу своего персонажа с силой персонажа другого игрока, например, заглянув во внутриигровой рейтинг «Top Power».
Чтобы посчитать нашу силу, нужно воспользоваться следующей формулой:

Сила (PvE) = Сила характеристик + Сила сопротивлений + Сила уровня + Сила бонусов + Сила орбов

Сила характеристик = (Сила + Ловкость + Мощь + Знание + интеллект) + (2 × урон оружия) + [(здоровье + Выносливость + Мана) / 10]

Где:

  • в расчёт берётся сумма характеристик, видная в окне характеристик персонажа.

Сила сопротивлений = [0,4 × (сопротивление рубящим + сопротивление колющим + сопротивление дробящим)] + [0,3 × (сопротивление огню + сопротивление холоду + сопротивление энергии)] + (0,6 × сопротивление менталу)

Где:

  • сопротивления считаются в очках, а не в процентах.

Сила уровня = [уровень * (уровень + 1)] / 8

Где:

  • уровень — уровень нашего персонажа

Сила бонусов = (кол-во мод. A × множитель мод. A) + (кол-во мод. B × множитель мод. B) + (...) + (кол-во мод. Z × множитель мод. Z)

Где:

  • кол-во мод. — величина модификатора на персонаже в виде числа (т. е. 10% = 10, а не 0,1)
  • множитель мод. — множитель модификатора из таблицы множителей
  • A / B / Z — пример бонуса

Чтобы рассчитать силу орбов, нужно сложить значения всех посчитанных по отдельности орбов, силу которых считаем по формуле:

Сила орба = (коэф. орба + коэф. качества) × коэф. категории

Где:

  • коэф. орба — коэффициент орба
  • коэф. качества — коэффициент качества снаряжения, в которое вставлен орб
  • коэф. категории — коэффициент категории, к которой относится орб
