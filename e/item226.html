Описание

Используется при создании Средний ангидрид.
Для добычи требуется Бутыль из толстого стекла.
-

Где найти

Побережье, Корабль, Корабль - уровень II

Применение

  • Ингредиент для изготовления Среднего ангидрида.

Как добыть

Палинку можно собрать из бочек в инстансе Ихтиона — Обломках корабля.

Чтобы собирать, нужно сначала купить Бутыль из толстого стекла.
