Описание

Душа вождя Ворлингов, чья ненависть открывает проход в тюрьму Ангвальф-Хтага.
Можно создать из камней ворлингов Камни ворлингов, а также получить во время различных игровых ивентов, также есть шанс получить за выполнение задания у Кимерул-Маг.
Для создания 1 души требуется 4 камня ворлингов Камни ворлингов и 10x Эссенция.
Душа вождя ворлингов, чья ненависть открывает проход в тюрьму Ангвальф-Хтаги.

Рецепт

Создание: 2x Воэ + 2x Вии + 10x Эссенция
Создание: 2x Нов + 2x Эов + 10x Эссенция
Создание: 2x Воэ + 1x Вии + 1x Эов + 10x Эссенция
Создание: 1x Вии + 2x Нов + 1x Эов + 10x Эссенция
Создание: 1x Воэ + 2x Вии + 1x Нов + 10x Эссенция
Создание: 1x Воэ + 1x Нов + 2x Эов + 10x Эссенция

Применение

  • Позволяет войти в инстансы Тюрьма Ангвальф-Хтаги.

Как добыть

Получаем за победу над:
  • Шазза-маг
  • Эой-лучник
  • Кхаагар-варвар
  • Джеовалл-друид
  • Юргао-рыцарь
  • Шид Саи
