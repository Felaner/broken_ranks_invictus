Описание

Сувенир из бурного прошлого Беирна. Магический артефакт, служащий для призыва Селена. Из дошедших до вас слухов вы делаете вывод, что когда вы добудете Кости Халигардийца, Рука Халигардийца, Череп Халигардийца, Останки Халигардийца, Халагар из Беирна поведает вам, как призвать Селена.
Память о бурном прошлом Беирна. Предмет нужен для призыва Селены.

Из подслушанных слухов ты понимаешь: когда добудешь ещё Кости, Руку и Череп галигардца, Халагар из Беирна расскажет, как призвать Селену.

Дроп

Клещ Ястребенок Як

Применение

  • Один из предметов, нужных для призыва Селены в инстансе Кладбище в горах,
  • Один из предметов, нужных для изготовления Эфирной лампы.
  • Для завершения поручения Снятие клещей.
