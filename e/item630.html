Описание

Используется для создания Заряженный элемент питания.
Для получения требуется выполнить задание у Трун около складов Лукас Ландау.
Можно получить во время различных игровых ивентов, также есть шанс получить за выполнение задания у Рок Оллон.
Разряженный элемент для пульта. Чтобы зарядить, используй особую печь в Зале управления.

Где найти

Аларил, Распутье, Владения Ландау

Применение

  • Для переработки в особой печи в Заряженный элемент питания.

Способы получения

  • Получаем за выполнение поручения Элемент питания у Труна в Поместье Ландау.

Упоминается в

Фракции, Зал Конструкта v1
